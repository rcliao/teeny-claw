# 🦀 teeny-claw

A minimal, self-improving autonomous agent framework in Go.

## What is this?

teeny-claw is a tiny but sharp autonomous agent that:
- Wraps coding CLIs (Claude Code, Codex, etc.) as its brain
- Manages its own memory and gets smarter over time
- Executes tools and self-corrects on failures
- Runs scheduled autonomous work sessions

## Quick Start

```bash
go build -o bin/teeny ./cmd/teeny
./bin/teeny run
```

## Why?

Because OpenClaw is amazing but massive. Sometimes you want a tiny, focused agent loop you fully understand and control — one that gets better at its job every time it runs.
